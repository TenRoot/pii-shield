Sources of the license texts in this folder
===========================================

The Tesseract installer (UB Mannheim build 5.5.3.20260724) is built with MSYS2 MINGW64
packages (the DLLs hold "Built by MSYS2 project" strings). Each text below is copied unchanged
from the MSYS2 package of the version in the DLL (share/licenses/<package>/), or, when the
package holds no license file, from the upstream release of that version. A version that the
DLL does not show is the newest MSYS2 package before the installer date (2026-07-24).
Retrieved 2026-11-25.
